# adap2e_hardware

## 1) Overview

`adap2e_hardware` provides the live `ros2_control` hardware plugin for Adap2e mobile bases.

It specializes the generic `4WS4WD` hardware abstraction from `romea_mobile_base_hardware` and implements the communication with the Adap2e low-level controller through SocketCAN.

The exported plugin is:

| Plugin | Base class | Mobile base architecture |
|---|---|---|
| `adap2e_hardware/Adap2eHardware` | `HardwareSystemInterface4WS4WD` | `4WS4WD` |

## 2) Hardware concept

`Adap2eHardware` is loaded by `controller_manager` from the `<ros2_control>` description generated by `adap2e_description`.

At runtime, it:

1. reads the Adap2e `ros2_control` hardware information;
2. creates the `HardwareInterface4WS4WD` command and state interface mapping;
3. opens CAN communication on `can0`;
4. starts a receiver thread for Adap2e feedback frames;
5. converts controller commands into Adap2e CAN frames;
6. converts received CAN feedback into `ros2_control` state interfaces.

From the controller point of view, this behaves like a standard mobile base hardware plugin: `romea_mobile_base_controllers/MobileBaseController4WS4WD` writes wheel steering and wheel speed commands to command interfaces, then reads feedback from state interfaces to compute odometry.

## 3) CAN communication

The hardware plugin sends commands for:

* front wheel linear speeds;
* rear wheel linear speeds;
* front wheel steering angles;
* rear wheel steering angles;
* start/stop autonomous mode.

It receives feedback for:

* front wheel linear speeds;
* rear wheel linear speeds;
* front wheel steering angles;
* rear wheel steering angles.

The current implementation uses the `can0` SocketCAN interface.

## 4) Relation with other packages

`adap2e_hardware` is the live hardware specialization of the Adap2e mobile base:

* `adap2e_description` selects `adap2e_hardware/Adap2eHardware` in `live` mode;
* `romea_mobile_base_hardware` provides the reusable `4WS4WD` hardware abstraction;
* `romea_mobile_base_utils` provides helpers used to read `hardware_interface::HardwareInfo`;
* `romea_mobile_base_controllers` sends commands through the exported `ros2_control` interfaces;
* `adap2e_bringup` starts the controller manager and loads this hardware plugin in live mode.
